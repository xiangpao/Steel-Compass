# 批次 0：钢与木模块验证证据清单

本清单只证明有限力学模型已有可重复的独立复算，不代表专业验收完成。八个模块均保持 `unverified`；在规范条文逐项签署、人工手算记录、复核人及日期补齐前，不得修改为 `independently_verified`。

| 模块 | 当前独立证据 | 仍缺少的发布证据 |
|---|---|---|
| `steel_beam` | 简支/悬挑均布荷载反力、弯矩、剪力、弹性挠度及截面承载力闭式解 | 条文签署；无侧向约束开口截面整体稳定 |
| `steel_column` | SHS/RHS 截面性质、长细比、当前稳定系数及线性压弯相互作用复算 | 完整压弯条文、二阶效应和曲线人工签署 |
| `portal_frame` | 对称竖向及水平整体平衡、反力符号 | 独立矩阵求解器、内力/位移全量黄金算例、二阶效应 |
| `steel_baseplate_anchor` | 底板承压/条带弯曲、锚栓钢材拉剪和焊缝快算 | 混凝土锥体、拔出、劈裂、撬力及锚固长度 |
| `steel_cantilever_post` | 面板风合力、柱底弯矩和扭矩平衡 | 完整钢柱稳定方法和连接破坏模式 |
| `timber_beam` | 矩形梁弯剪、反力及挠度闭式解 | 湿度、长期、缺口、侧向稳定、连接及耐火 |
| `timber_column` | 当前欧拉/材料上限筛查复算 | GB 50005 完整稳定系数方法及调整系数 |
| `timber_deck_panel` | 单向简支条带弯剪与挠度闭式解 | 横向分配、连接、湿度及长期变形 |

机器可读的适用范围、公式/规范映射、黄金算例、边界项和缺口位于 `steel_timber_evidence.py`；纯独立力学复算位于 `steel_timber_references.py`，其中没有导入 `app.core`。

所有模块共用 `screening_passes` 边界判定基准：需求为承载力的 `0.99` 倍必须通过，`1.01` 倍必须失败。该断言只验证结论边界，不替代每种破坏模式的规范推导。
