Support nonlinearity/Basic soil spring

Definition, application

Support nonlinearity is nonlinear functionality which can be apply on any type of supports. These features can simulate special nonlinear behaviour of supports. For taken into account it is necessary to perform nonlinear analysis.

Where to find it

In project data dialog in part 'Functionality' it is necessary to switch ON 'Support nonlinearity/Basic soil spring'. After that in support properties there are several new possibilities which can be set for any degree of freedom.

Possibilities

Support nonlinearity Description
"Rigid compression-only support" This type of support gives a full support (fixing) when under compression
Rigid tension only This type of support gives a full support (fixing) when under tension
"Flexible compression-only support" This type of support gives a partial support (behaving like a spring) when under compression
Flexible tension only This type of support gives a partial support (behaving like a spring) when under tension
"Non-linear functions" Non-linear function defines change of stiffness given by the graph

Limitations

- For support - surface (el.foundation) with type 'individual' it is possible to set only 'Nonlinear'.

- Support - surface (el. foundation) with type 'soil-in' is in nonlinear analysis automatically taken into account as 'press only'.
