# 景观设计安全边界补充验证

2026-09-26；基线 `cc54f0d`；独立工作树 `Steel-Compass-audit`，分支 `codex/landscape-safety-20260926`。新计算引擎 `3.9.0-beta.2`、空间适配器 `2.0`、构件筛查目录 `2026.2-unverified`；历史快照只读。

## 对产品用途的判断

软件可以帮助设计师改变柱的边长、壁厚、柱高、柱距和构件方向，观察受力与变形变化，发现超限和缺失条件。但目前不能给整个景观项目划出已获专业验证的安全区间，也不是自动形态优化器。**未完成不是安全，也不等于已经证明不安全。** 美观、视线、通行、净高与场地协调仍需设计判断；结构计算提供约束，不替代这些判断。

柱距必须连同梁跨、分担面积、屋面重量、风雪地震、支承、连接及基础一起重算。改变一根构件的外观尺寸，不能只根据单根柱的强度判断整体安全。

## 实际设计动作与验证范围

| 设计任务 | 本轮新增/复核的证据 | 尚不能据此保证的内容 |
|---|---|---|
| 柱变细、减薄壁厚 | 5组独立闭式截面/位移对照；150×6编辑、保存、刷新、真实分析 | 冷弯/制造圆角、腐蚀余量、节点刚度、沿杆二阶包络及完整规范稳定 |
| 增大柱距、提高柱高 | 3/4/5m开间的面积与竖向反力平衡；3/4m单柱位移；梁跨2/3/4m | 连续体系重分配不能用简单比例代替；并非给出通用最大柱距 |
| 改梁方向、悬挑长度 | RHS强弱轴独立悬臂回归；简支/悬挑6组闭式挠度 | 侧扭、刚接真实刚度、附墙锚固、上拔接触 |
| 屋面遮蔽、增重、开洞 | 重跑既有屋面分区、开洞、荷载分配与组合测试 | 开孔率气动力、积雪漂移、排水堵塞、覆土积水等项目专项 |
| 导视牌/入口增高或增大面板 | 场景参数到杆件/柱脚的契约审查；风反向与偏心能力登记 | 非线性柱脚、疲劳、涡激振动、真实面板风压和焊缝 |
| 景墙、围墙、挡土、种植池 | 逐变体能力矩阵；水深二次推力/三次弯矩验证 | 土参数、排水失效、主动土压力适用位移、地震水土作用 |
| 栈道、平台、景观桥、座凳 | 目录逐变体传力链执行与缺口登记 | 人群振动、栏杆水平力、舒适性、防滑、无障碍及施工节点 |
| 水池与地下水 | 水深/浮力敏感性；既有空池/满池与浮力一次计入回归 | 流水冲击、渗流、最高设计水位、施工阶段及水密性 |
| 缩小基础、基础贴边 | 同一长宽厚必须通过所有保存组合；正交弯矩反例 | 不提供已验证的最优基础，部分接触、沉降资料、配筋仍有缺口 |

目录10类40变体已重新执行并逐项记录在 [scene-variant-matrix.json](scene-variant-matrix.json)。该旧场景图 fixture 的结果为：6个 `ready`（3个筛查通过、3个筛查失败）、24个 `capability_unavailable`、10个 `stale`。按阻断原因归纳为7个柱脚接触能力阻断、27个专用输入转换缺失。**这不是40个完整可用场景。** fixture 中基础120kPa是显式测试假定，不是可用于工程的地勘数据；Geometry 2.3亭廊工作台另有独立分析入口。详情见 [场景契约审计](scenario-contract-audit.md)。

## 直观数值对照

以下固定1kN柱顶横向力、柱脚理想固接、无轴压、E=206000MPa、尖角方管、小变形线弹性；不包含真实场景全部作用，也不是选型建议。

| 方管 / 柱高 | 顶部位移 mm |
|---|---:|
| 100×100×4 / 3m | 18.485854 |
| 150×150×4 / 3m | 5.260441 |
| 150×150×6 / 3m | 3.651527 |
| 200×200×6 / 3m | 1.494496 |
| 150×150×6 / 4m | 8.655471 |

同梁截面、同2kN/m线荷载，简支跨度从3m到4m，挠度从0.570803到1.804021mm（约3.16倍）；改悬挑后对应5.479713和17.318600mm。说明柱距与悬挑会迅速改变变形约束，不能仅靠加厚柱壁补偿。另以H/250为明确测试限值，0.99/1.01两侧结论正确翻转；该测试不将H/250声明为所有项目法定限值。

11组闭式参考与实际值全部在预登记1e-9相对误差内，最大实测约4.02e-11。数据、适用范围、单位、公式与容差在 [analytical-sweep.json](analytical-sweep.json)。公式来源为 [American Wood Council Design Aid 6](https://web-media.awc.org/wp-content/uploads/2021/12/17210710/AWC-DA6-BeamFormulas-0710.pdf)，Figure 1/12/13；仅借用弹性力学关系，钢材E由测试显式给定，不借用国外规范承载力。

```powershell
python -m pytest --cov=app --cov-report=term-missing
python -m verification.landscape_safety_cases ../docs/landscape-validation-20260926/analytical-sweep.json
python -c "from verification.audit_public_cases import run; r=run(); assert len(r['cases']) == 8 and all(x['passed'] for x in r['cases'])"
```
